Install on Android

  1. If this page is open inside Facebook, email, or a message, use its menu to open the page in your full browser.
  2. Tap the correct Android download button above. Continue only when the download address is on github.com/terry77075 and the filename matches the one shown.
  3. Open the downloaded APK from your browser's Downloads list or the Android Files app.
  4. If Android asks, allow installation only for the browser or Files app you are using. Keep Play Protect and other security protections enabled.
  5. Install over an existing copy when updating. Do not uninstall first; uninstalling can remove locally stored data. Back up anything important before updating.
