Install the beta

Choose your phone

Use the official TestFlight invitation on Apple devices or the existing published GitHub release on Android.

iPhone and iPad

  1. Install Apple's TestFlight app if you do not already have it.
  2. Tap Join on iPhone or iPad above and accept the public beta invitation.
  3. In TestFlight, tap Install or Update.

Android

  1. Tap Download for Android. The official file is RideLoop-Beta.apk on github.com/terry77075.
  2. Open the downloaded APK. Android may ask you to allow installs from the browser or Files app you used.
  3. Install over your existing beta to keep local data. Do not uninstall first. Keep Play Protect and other security protections enabled.
